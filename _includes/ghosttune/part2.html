// Capabilities

Professional tuning tools without a laptop.

Every screen is designed around a real tuning workflow rather than a desktop interface compressed onto a phone.

📊 VE table editing

Read, edit, temporarily write, burn, and verify the primary VE table with live operating data and cell-level controls.

⚡ Ignition and AFR tables

Edit supported ignition and AFR target tables using profile-defined addresses, scales, and guarded write paths.

📡 Live ECU dashboard

Monitor RPM, TPS, MAP, coolant temperature, AFR, intake temperature, battery voltage, and ignition advance.

🔧 Startup and calibration

Purpose-built screens for cranking, priming, after-start enrichment, warm-up, sensor calibration, idle, and related setup.

💾 Tune files and backups

Save, compare, export, and restore supported tune data while keeping a known-good backup available.

👻 Ghost Guide

Contextual in-app guidance explains screens, parameters, safety considerations, and common tuning concepts.

🛰 Connection diagnostics

Inspect connection health and communication behavior before relying on the link for ECU changes.

🧪 Demo Mode

Explore the complete interface with simulated data before connecting to live hardware.

🔒 Guarded write workflow

Writes use coordinated polling pauses, response validation, burn sequencing, re-reading, and verification with interruption handling.

// Setup

A direct local connection.

GhostTune communicates with the ECU through a WiFi-to-RS232 bridge. There is no cloud relay and no cable attached to the iPhone or iPad.

Connect the bridge

Attach a compatible bridge to the ECU diagnostic serial port and provide the bridge with power.

Join its WiFi network

Connect the iPhone or iPad to the bridge’s local access point in device settings.

Verify compatibility

GhostTune identifies the ECU profile and keeps unsupported write paths blocked.

Read, edit, and verify

Back up the tune, make supported changes, and use the guarded temporary-write or permanent-burn workflow.
