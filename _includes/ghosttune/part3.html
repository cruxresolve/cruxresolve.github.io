GhostTune FAQ

GhostTune is currently verified on MicroSquirt hardware running MS2/Extra 3.4.4 firmware. Other ECU platforms and firmware versions are not represented as supported unless they are explicitly added to the compatibility table after validation.

GhostTune uses guarded sequencing, response validation, re-reading, and verification. If an interruption or mismatch is detected, the app stops the operation, reports the detected state, and provides recovery guidance. No software can guarantee protection from every power, hardware, or firmware failure, so a known-good backup remains essential.
