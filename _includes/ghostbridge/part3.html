// GhostBridge FAQ

Common serial-bridge questions.

Can GhostBridge be used without GhostTune?

Yes. GhostBridge itself relays bytes between its local TCP connection and RS232 interface and is not software-locked to GhostTune. Non-GhostTune configurations are not represented as verified unless Crux Resolve explicitly lists them.

Is GhostBridge a general RS232-to-WiFi adapter?

GhostBridge is a local TCP-to-RS232 WiFi bridge designed first around the GhostTune workflow. It can serve other compatible serial applications, but every RS232 or DB9 device should not be assumed compatible without checking the complete interface and software requirements.

How do I connect to the GhostBridge WiFi network?

Select the network named GhostBridge-XXXXX in your phone, tablet, or computer WiFi settings. The password is 1234 followed by the last four characters of that WiFi name. For example, GhostBridge-ABCDE uses password 1234BCDE. The device-specific password helps prevent nearby GhostBridge units from sharing the same credentials.

Does GhostBridge require internet access or a router?

No. GhostBridge creates its own local WiFi access point. A compatible TCP client connects directly to the bridge at 192.168.4.1:35000.

What is verified today?

The published verified configuration is GhostTune with MicroSquirt hardware running MS2/Extra 3.4.4. Additional verified applications can be added as they are specifically tested.
