// Compatibility checklist

Will GhostBridge work with my device?

A strong candidate uses

  • True RS232 electrical signaling rather than TTL serial, RS485, CAN, or another interface.
  • Three-wire communication using TX, RX, and GND.
  • A compatible DTE/DCE pinout or cabling arrangement.
  • Serial settings that the installed GhostBridge firmware can match.
  • Host software that can communicate through TCP or through a compatible TCP-to-virtual-COM layer.
  • No required RTS/CTS, DTR/DSR, DCD, RI, or other modem-control signals.

Current GB-01 boundaries

  • DB9 male: pin 2 RX, pin 3 TX, pin 5 GND.
  • Current hardware does not route RTS/CTS or other modem-control lines.
  • A DB9 connector alone does not prove the device uses compatible RS232 signaling.
  • Some DTE-to-DTE or DCE-to-DCE combinations require a null-modem/crossover cable.
  • Unusual timing, BREAK behavior, nonstandard UART modes, or application-specific control-line behavior may require additional validation.
  • For repeat deployments or application-specific firmware behavior, see Custom & OEM Serial Solutions.
Do not connect by connector shape alone: confirm the device documentation identifies a compatible RS232 interface and pinout before connecting GhostBridge.
Verified automotive use: GhostTune with MicroSquirt hardware running MS2/Extra 3.4.4 remains the currently published verified ECU configuration. That verified application does not limit the GB-01 hardware to ECU use.

// GhostBridge FAQ

Common serial-bridge questions.

Can GhostBridge be used without GhostTune?

Yes. GhostBridge is a transparent local TCP-to-RS232 bridge and is not software-locked to GhostTune. A non-GhostTune device still has to meet the GB-01 electrical, signal, serial, cabling, and host-software requirements.

What RS232 signals does GB-01 provide?

The current GB-01 provides standard 3-wire RS232: DB9 pin 2 RX, pin 3 TX, and pin 5 ground. RTS/CTS, DTR/DSR, DCD, RI, and other modem-control lines are not connected.

Does GhostBridge require internet access or a router?

No. GhostBridge creates its own local WiFi access point. A compatible TCP client connects directly to the bridge at 192.168.4.1:35000.

Can it carry binary serial data?

Yes. GhostBridge relays serial bytes transparently in both directions. It does not need to understand the device's application protocol in order to transport the data.

Will every DB9 device work?

No. DB9 is only a connector. The connected device must use compatible RS232 signaling, pinout, serial settings, timing behavior, and host software.

Does GB-01 support RTS/CTS?

No. The current production GB-01 does not route the MAX3232's unused second channel to the DB9 connector, so hardware RTS/CTS flow control is not available.

Do I need a null-modem cable?

It depends on the other device's DTE/DCE arrangement. Some equipment connects straight-through; other combinations require TX/RX crossover through a null-modem cable or adapter.

What is verified today?

The currently published verified automotive configuration is GhostTune with MicroSquirt hardware running MS2/Extra 3.4.4. Other devices can be evaluated against the same published GB-01 interface requirements.
