// What it does

A transparent local RS232 bridge.

GhostBridge moves serial bytes between standard 3-wire RS232 and a local TCP connection. It does not need to understand the device's application protocol, which makes the same hardware useful across compatible automotive, embedded, industrial, test, and legacy serial applications.

↔️ Standard 3-wire RS232

GB-01 uses a DB9 male connector with pin 2 RX, pin 3 TX, and pin 5 ground. The current hardware is intended for devices that communicate over TX, RX, and GND without required modem-control lines.

📡 Its own WiFi network

No router or internet connection is required. A phone, tablet, computer, or other compatible TCP client can connect directly to the bridge's local access point.

🔁 Transparent TCP transport

GhostBridge relays bytes in both directions between RS232 and TCP instead of interpreting ECU commands, instrument messages, or another application protocol.

🔐 No cloud dependency

Serial traffic stays on the direct local connection. GhostBridge does not require a cloud relay, account, subscription, or internet service to move data.

🧰 Assembled hardware

The bridge arrives assembled in an enclosure with accessible DB9 RS232 and USB-C power connections for practical bench, garage, and field use.

✅ Verified automotive use

GhostTune with the published MicroSquirt / MS2/Extra 3.4.4 configuration is one verified production application of the broader serial-bridge hardware.

// Where it can fit

Built around the interface, not one application.

A compatible device does not need to be an ECU. The important questions are whether it uses true RS232, the required signals are available on GB-01, its serial settings can be matched, and the host software can communicate through TCP or a suitable TCP-to-COM layer.

Industrial & automation

Controllers, meters, programming/configuration ports, and other equipment using compatible standard 3-wire RS232 interfaces.

Test & measurement

Benchtop instruments, data loggers, laboratory equipment, and measurement devices that communicate over compatible RS232.

Embedded & custom hardware

Controllers, development systems, and purpose-built products that expose a compatible RS232 serial interface.

Automotive & diagnostics

Legacy equipment

// Technical specifications

Know the interface before you connect it.

Serial side

  • Electrical interface: RS232 through a MAX3232 transceiver.
  • Connector: DB9 male.
  • Pin 2: RXD into GhostBridge.
  • Pin 3: TXD out of GhostBridge.
  • Pin 5: signal ground.
  • Current hardware flow control: none. RTS/CTS, DTR/DSR, DCD, RI, and other modem-control lines are not connected.

Network & power side

  • WiFi mode: local access point.
  • Default address: 192.168.4.1.
  • Default TCP port: 35000.
  • Transport behavior: transparent bidirectional serial byte relay over TCP.
  • Internet / cloud: not required.
  • Power: USB-C input.
Serial settings still matter: baud rate, data bits, parity, stop bits, cabling, timing expectations, and host-software behavior must match the connected device. Firmware capabilities determine which serial configurations are available on a given GhostBridge release.
// Basic connection

Three pieces make the link.

Connect RS232 and power

Connect a compatible standard 3-wire RS232 device to the DB9 interface and power GhostBridge through USB-C. Depending on the DTE/DCE arrangement, your installation may require a straight-through or null-modem/crossover cable.

Join the bridge network

Select the network named GhostBridge-XXXXX. The password is 1234 followed by the last four characters of that WiFi name. Example: GhostBridge-ABCDE uses password 1234BCDE.

Connect the client

Use compatible software to open a TCP connection to 192.168.4.1:35000. Legacy desktop applications that require a COM port may need a suitable TCP-to-virtual-COM solution.
