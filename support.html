// Frequently asked questions

Common answers

Can GhostBridge be used without GhostTune?

Yes. GhostBridge is a transparent local TCP-to-RS232 byte relay and is not software-locked to GhostTune. The current GB-01 is intended for compatible standard 3-wire RS232 equipment using TX, RX, and ground.

What RS232 signals does GhostBridge provide?

The current GB-01 uses DB9 pin 2 for RX into GhostBridge, pin 3 for TX out of GhostBridge, and pin 5 for ground. RTS/CTS and other modem-control lines are not routed on the current production hardware.

Does GhostBridge require internet access?

No. GhostBridge creates its own local WiFi access point, so a compatible client can connect directly without a router, cloud service, or internet connection.

Does every DB9 device work with GhostBridge?

No. A DB9 connector alone does not establish compatibility. The device must use compatible RS232 signaling, pinout, serial settings, timing behavior, cabling, and host software.

Do you offer custom GhostBridge firmware?

Crux Resolve can evaluate application-specific firmware behavior, serial/network defaults, repeat deployments, and OEM integration needs case by case. See Custom & OEM Serial Solutions.

What GhostBridge application is verified?

The currently published verified automotive application is GhostTune with MicroSquirt hardware running MS2/Extra 3.4.4. That verified use does not make the underlying GB-01 transport ECU-specific.

What ECUs does GhostTune support?

The current release is verified with MicroSquirt hardware running MS2/Extra 3.4.4. Only ECU configurations explicitly listed by Crux Resolve should be treated as supported.

How does GhostTune connect to the ECU?

GhostTune connects over local WiFi through a compatible WiFi-to-RS232 bridge. GhostBridge GB-01 is the assembled hardware designed and verified for the published GhostTune workflow.

Is tune data sent to the cloud?

No. ECU communication and tune data stay on the device and local WiFi link unless the user deliberately exports or shares a file.

Is GhostTune available now?

Yes. GhostTune v1.0 is available on the App Store.

How do I report a problem?

Email support@cruxresolve.com with the product or device model, operating-system version, firmware version if relevant, what you expected, and what occurred. Screenshots, logs, or a short screen recording can help when appropriate.
