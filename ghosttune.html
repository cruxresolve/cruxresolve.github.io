Current product status

GhostTune

  • Independent ECU tuning application for iPhone and iPad.
  • GhostTune v1.0 is available on the App Store.
  • Currently verified with MicroSquirt hardware running MS2/Extra 3.4.4.
  • Live ECU communication uses a compatible local WiFi-to-RS232 bridge.
  • No GhostTune account or subscription is required.
  • Live data, tune files, VE/ignition/AFR table editing, diagnostics, Demo Mode, contextual guidance, and guarded ECU changes.
  • Only configurations explicitly listed by Crux Resolve should be described as supported.

GhostBridge

  • GhostBridge v1.0 (GB-01) is an assembled WiFi-to-RS232 bridge available now for $89.
  • DB9 RS232 interface and USB-C power.
  • Creates its own local WiFi access point; no router or cloud service is required for the working connection.
  • Default local endpoint: 192.168.4.1:35000.
  • Published verified use: GhostTune with MicroSquirt hardware running MS2/Extra 3.4.4.
  • Typical fulfillment within 2–4 weeks.
Approved safety description: GhostTune distinguishes temporary and permanent ECU changes and checks returned ECU data before reporting supported changes as complete. A known-good backup and safe working environment remain essential.

About GhostTune

GhostTune brings ECU tuning to iPhone and iPad. The current verified configuration uses MicroSquirt hardware running MS2/Extra 3.4.4 through a direct local WiFi-to-serial connection. The application combines live ECU data, VE/ignition/AFR table editing, tune-file tools, contextual guidance, diagnostics, Demo Mode, and guarded ECU changes without requiring a laptop, cloud account, or subscription. GhostTune v1.0 is available on the App Store.
