About GhostTune

GhostTune brings a professional ECU tuning workflow to iPhone and iPad. The current live-test configuration uses MicroSquirt hardware running MS2/Extra 3.4.4 through a direct local WiFi-to-serial connection. The application combines live ECU data, table and calibration screens, tune-file tools, contextual guidance, diagnostics, Demo Mode, and guarded write sequencing without requiring a laptop, cloud account, or subscription.
