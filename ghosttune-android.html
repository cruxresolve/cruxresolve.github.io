// GhostTune for Android · Development update · October 23, 2026

GhostTune for Android: MicroSquirt ECU connectivity in beta testing.

Searching for an Android ECU tuning app for MicroSquirt or MS2/Extra? GhostTune is being ported to Android, with WiFi, Bluetooth Classic SPP, Bluetooth Low Energy (BLE UART), and USB-C OTG serial connection paths under beta evaluation.

Current status: Android beta testing, not a public Android release. Connection methods and adapter families below describe development support, not a promise that every phone, adapter, ECU, or write operation has passed hardware testing.

// Android connection options

More ways to reach a serial-connected ECU.

An Android phone can use different physical and wireless paths depending on its hardware, the adapter protocol, and what the beta implementation has verified. An Android Bluetooth ECU connection is not the same thing as a generic OBD-II Bluetooth scanner.

WiFi ECU connection

The established GhostTune transport uses a compatible local WiFi-to-RS232 bridge. The verified public tuning setup is on iPhone/iPad; Android use is still part of beta validation.

Bluetooth Classic (SPP)

The Android port includes a Bluetooth Serial Port Profile connection path for serial Bluetooth devices. Physical adapter compatibility and live ECU behavior are being tested.

Bluetooth Low Energy (BLE UART)

Android BLE UART support is under development for compatible BLE serial peripherals. BLE support does not mean every BLE or OBD-II accessory will work.

USB-C OTG / USB serial

The Android USB Host implementation uses the open-source usb-serial-for-android v3.11.0 library. The current USB serial pilot explicitly limits ECU commands to read-only operations while validation continues.

// Android USB OTG compatibility

USB-C to serial for Android: driver families being evaluated.

For USB OTG, GhostTune uses Android's USB Host framework with an application-level serial driver library—not a special kernel driver or root-only setup. The library recognizes several common USB-to-serial chipsets, including the families below. Library recognition is not the same as verified GhostTune-to-ECU compatibility.

// MicroSquirt / MS2/Extra

What works today versus what Android is testing.

GhostTune's public iPhone/iPad application is production-verified for MicroSquirt hardware running MS2/Extra 3.4.4 through a compatible local WiFi-to-RS232 bridge. That is the published write-capable configuration.

The Android beta extends GhostTune's transport options, but it has not yet earned the same published production verification for ECU editing, write/burn safety, or all adapter combinations. In particular, the Android USB OTG pilot enforces a read-only command policy. Support for MS3, MS3Pro, Speeduino, rusEFI, or other controllers must not be assumed until individually qualified.

Before connecting an Android phone to an ECU

  1. Identify your ECU hardware and exact firmware version.
  2. Check whether its serial interface is true RS232, TTL, or another electrical standard.
  3. Confirm the adapter, pinout, baud rate, Bluetooth profile or USB chipset, and power needs.
  4. Use only a beta build and workflow provided for your tested configuration; do not assume live write support.

// Questions Android owners are asking

GhostTune Android FAQ

Is there an Android MicroSquirt tuning app available to download?

GhostTune for Android is in beta testing. There is no announced public Google Play release or verified production Android tuning configuration yet. The released GhostTune app is currently available for iPhone and iPad.

Can I connect MicroSquirt to an Android phone over Bluetooth?

Android Bluetooth Classic SPP and BLE UART paths have been added for beta testing. Whether your particular MicroSquirt serial adapter works will depend on its hardware, Bluetooth profile, and validation results. No universal Bluetooth adapter compatibility is claimed.

Will a USB-C OTG cable and USB-to-RS232 adapter work?

The Android USB Host serial pilot can enumerate supported driver families, ask for USB permission, and communicate through a serial port. It currently restricts ECU commands to a read-only safety policy. A correct cable and serial electrical interface are still required, and physical ECU/adaptor testing is pending.

Is GhostTune the same as an Android OBD-II or ELM327 scan tool?

No. GhostTune is designed for supported aftermarket engine-management ECU protocols, not generic ELM327 vehicle diagnostics. Bluetooth and USB support do not change that distinction.

Do I need GhostBridge with GhostTune on Android?

GhostBridge GB-01 is the verified WiFi hardware for the published iPhone/iPad MicroSquirt setup. Android SPP, BLE and USB OTG development aims to offer additional transport choices; no particular third-party adapter is yet advertised as verified for the Android beta.

Can the Android beta change fuel or ignition tables?

Do not assume production-ready Android write capability. The USB serial pilot is read-only by design, and write/burn features over other Android transports require independent validation before they are listed as supported.
