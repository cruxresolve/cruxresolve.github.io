GhostTune v1.0 historical release update

This page originally documented an earlier GhostTune release milestone. It has been condensed so older product-status information does not compete with the current product pages.

Current status: GhostTune v1.0 is available on the App Store. GhostBridge GB-01 is the currently available Crux Resolve RS232-to-WiFi bridge.

Current GhostTune information

GhostTune is available for iPhone and iPad. The current published verified ECU configuration is MicroSquirt hardware running MS2/Extra 3.4.4 through a compatible local WiFi-to-RS232 bridge.

For current features, compatibility, App Store access, and support information, use the GhostTune product page.

Current GhostBridge information

GhostBridge GB-01 is an assembled local RS232-to-WiFi TCP bridge available through Crux Resolve. Current pricing, compatibility details, setup instructions, and ordering information are maintained on the GhostBridge product page.
