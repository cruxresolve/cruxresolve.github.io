What GhostTune checks during live ECU use

GhostTune is designed to make the connected ECU state clear before, during, and after supported calibration changes. The current release is available on the App Store for the published MicroSquirt configuration.

Current verified configuration: MicroSquirt hardware running MS2/Extra 3.4.4 through a compatible local WiFi-to-RS232 connection.

Supported configuration

Before a live tuning workflow is used, the connected ECU and firmware must match a configuration explicitly supported by GhostTune. A working WiFi connection alone does not establish ECU compatibility.

Live data

Live values provide an immediate check that the complete connection is behaving as expected. RPM, throttle position, MAP, temperatures, AFR, and battery voltage should respond in believable ways for the vehicle's current condition.

Backups before changes

Keep a known-good tune backup before making meaningful calibration changes. A backup gives you a known reference if a later adjustment produces an unexpected result.

Temporary and permanent changes

GhostTune keeps temporary changes separate from permanent storage. This makes it possible to evaluate a supported adjustment before deciding whether it should remain after an ECU power cycle.

Result checking

After a supported ECU change, GhostTune reads the affected information again and compares the result with the requested change. If the returned state does not match, the app reports the mismatch instead of presenting the operation as successful.

Connection interruptions

If communication is interrupted, treat the ECU state as unresolved until the connection is restored and the relevant values are confirmed. GhostTune reports detected interruptions rather than assuming a completed operation.

What the user should confirm

  • The ECU and firmware match the published supported configuration.
  • The phone or tablet remains connected to the correct local WiFi network.
  • Live values are believable before making changes.
  • A known-good tune backup is available.
  • Any reported mismatch or interruption is resolved before continuing.
